# Minecraft-Motd-For-Discord
VIETNAMESE VERSION:
Đây là một Discord Bot cho phép bạn gửi trạng thái server minecraft vào máy chủ discord
Cách sử dụng
1: Tìm các dòng dưới đây trong file main.js lẫn deploy-commands.js và thay thế
const token = "";        // token bot
const clientId = "";     // Application ID từ Developer Portal
const guildId = "";      // Server discord ID
const serverIP = ""; // server IP của server Minecraft
const serverPort = 25653; // server port của server Minecraft

Sau khi xong , vào discord và dùng /status để hiện thị trạng thái server

1: Locate the following lines in both main.js  and deploy-commands.js and update them
const token = "";        // Bot token
const clientId = "";     // Application ID from the Developer Portal
const guildId = "";      // Discord server ID
